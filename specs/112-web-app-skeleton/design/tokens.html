panelator web app tokens

One token set for the product's web app, fixed by spec 112's design and inherited by every later web child. The three stories carry it in web-kit.tsx; the app's stylesheet in src/app/ carries the same custom properties and maps them into Tailwind's theme (see "Tailwind mapping" below). A later child extends the set only through its own design.

One theme, dark. The centre of this app will be a simulated LED panel: light sources on black. A dark surround shows those colours and their glow as they look on the wall, and the app is often used beside the real panel in a dim room. One theme also keeps every later design to one set of renders. The components read colours only through these names, so a light theme can be added later as a second value set by its own design, without touching a component.

This is the product's own set, not the console's (spec 051): the console keeps the base light values and its own extensions.

The base values name the widths the design stage renders at; a layout that changed exactly at 1440px would give a 1280px laptop the tablet layout, so the product's breakpoints sit below the render widths. A media query cannot read a custom property, so a stylesheet writes 720px and 1200px there; that is the one place a token's value is repeated.

Tailwind mapping

The app's stylesheet declares the custom properties above on :root and maps them in @theme, clearing Tailwind's defaults for each namespace so that a utility for a value outside the set does not exist. The right-hand names are Tailwind 4's theme namespaces as this design understands them; what is fixed here is the token names, their values and that utilities resolve to them, and the implementation uses whichever namespace of the installed Tailwind yields these utilities:

Focus: a 2px --color-focus outline, offset 2px, on :focus-visible for every link and button, the name in the band included. The offset puts the ring on the page or band colour, where it reads at 17:1 or more, whatever the control's own fill. Pressed has no look of its own beyond hover. There is no disabled control on these screens.
