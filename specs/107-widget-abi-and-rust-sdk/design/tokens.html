Spike widget tokens

One token set for the four screens in this directory. There are two kinds. The LED colours are the design itself: the values the three spike widgets pass to the host, which the implementation takes from flow.md. The page tokens only dress the design sheets around the pixels (the base tokens of tools/design-stage/src/tokens.css and four extensions); nothing on a panel uses them.

LED spacing

The unit is one LED. spike-clock keeps one LED of margin left and right of the seconds bar, two blank rows between the time's ink, the separator, the bar and the date's ink, and one blank row at the bottom. spike-scroll and spike-image draw edge to edge. There are no radii on a panel: the only curve is the seconds circle, radius 3.
