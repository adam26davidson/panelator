Maintainer console tokens

One token set for every screen in this directory. The stories carry it in console-kit.tsx; the console app's Tailwind theme (spec 051 section 5) maps these names one to one. Light theme only: the console has one user and the charter asks for nothing more; a dark theme would be its own validated step set, not an inversion.

Chart colours follow the entity, never the rank: slot 1 is always the current metric, slot 2 the metric it replaces, and the replaced line is dashed so the pair is told apart without colour. Values and labels use text tokens, never a series colour. Status colours (ok, warn, danger) always come with a word or icon.
