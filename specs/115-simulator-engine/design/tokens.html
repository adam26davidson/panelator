Spec 115 design tokens

The simulator page and Home use the product's one token set: spec 112's (specs/112-web-app-skeleton/design/tokens.html, in the app as web/src/app/styles.css), with every name and value unchanged. This design adds four tokens, marked new. The implementation adds them to web/src/app/styles.css with these names and values and nothing else; the stories load them from design.css in this directory. The theme is dark only, as spec 112 decided.

The panel's surround

The panel sits in a well (--color-surface, a 1px --color-border outline, --radius-md corners, 16px padding; on mobile it runs edge to edge with 12px above and below and no corners). Directly around the LEDs is a 1px --color-border-strong line: everything inside the line is panel. Its contrast is 5.8:1 against a black LED and 4.8:1 against the well, so a black LED at the edge is told from the page.
