# The firmware's first HIL runs (spec 106, issue #428, PR #492)

Written 2026-11-23 by the implement stage.

## What was measured

- ESP-IDF v5.5.6, `espressif/idf:v5.5.6@sha256:bf72fe7a15c22849a9a94147301165a545fb8905d97c176cf748e3e4614cac84` (the digest Docker Hub gives the tag; the image is 14.9 GB on disk, 5.4 GB compressed).
- Local build with `firmware/scripts/build.sh` once the image was cached: 1m28s. In CI the `build` job of `hil.yml` took 2m16s.
- `panelator.bin` is 0x39430 bytes (234,544), 22% of the 1 MB default app partition; the bootloader is 20,464 bytes.
- The `esptool` in the image is v4.12.0, so `esptool.py` and the `--flash_mode` spelling used by the harness are the ones it takes.
- The component manager of the image writes under `/opt/esp`, which only root owns, so `build.sh` mounts a tmpfs there; without it `idf.py` fails as a non-root user.

## The board

The board is attached by its **UART bridge port** (labelled TTL, a CH34x bridge, `/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0`), not by native USB. The harness found it with the default prefixes and `PANELATOR_HIL_PORT` unset. The chip reports `detected chip: boya` flash and 8192K of PSRAM, chip revision v0.2.
