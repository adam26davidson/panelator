Spec profile. You are writing, completing or reviewing a spec under `specs/`, the
design documents it hangs from, or an ADR under `docs/decisions/`. The required spec
sections and the issue's `Spec:` line are described in `specs/README.md` and spec 001
section 10. Every spec has a `Parent:` line naming its parent design, and that
parent's `## Children` section lists the spec's path. Text marked
`(maintainer answer, question #<id>)` records a maintainer decision: keep it as it is.
When reviewing, judge only against the criteria file provided.
